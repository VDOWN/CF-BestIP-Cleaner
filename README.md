# CF-BestIP-Cleaner

一个部署在 Cloudflare Workers 上的优选 IP 列表清洗与规范化工具，为 edgetunnel 等代理工具提供干净、去重、命名统一的订阅源。

## 背景与目的

在使用 edgetunnel 的优选 IP 功能时，通常会从多个动态更新的 TXT 链接读取节点列表。这些源存在几个问题：

- 内容格式不统一，夹杂时间戳、推广文字、测速信息等冗余片段。
- 不同来源之间 IP 重复，导致订阅里出现大量重复节点。
- 节点命名混乱，包含中文推广词、英文混杂、地区标签不统一。
- 部分源会输出带 `BestCF.pages.dev` 等字符的地址，不想让这些字符出现在最终节点名里。

最初的目标很简单：**把多个外部优选 IP 源抓取过来，按自己的规则清洗一遍，再输出成一个统一的订阅地址**，供 edgetunnel 读取。因为不想改 edgetunnel 本身的代码，所以把清洗逻辑独立成一个 Cloudflare Worker。

## 实现过程

整个项目是在 Cloudflare Workers 上从零搭建的，主要经历以下几个阶段：

1. **多源抓取**
   用 `Promise.allSettled` 并发请求多个 TXT 链接，单个源失败不影响整体，只丢弃失败源的结果。

2. **全局字符替换**
   用一张 `REPLACE_RULES` 映射表，把源里的推广词、时间戳、冗余标记替换成想要的内容或空值。例如：
   - `Gslege优选` → `Opt`
   - `【测速 Nodes】` → 空
   - `BestCF.pages.dev` → 空
   - `战争贩子 | US` → `🇺🇸 US`

3. **删除时间戳**
   用正则 `/\d{2}-\d{2}\s+\d{2}:\d{2}/` 匹配形如 `09-16 09:30` 的时间片段并删除，避免节点名里出现无意义的时间。

4. **按行首 IP 去重**
   从每行开头提取 IP，已出现过的 IP 整行丢弃，保证同一 IP 只保留第一次出现的记录。

5. **名称规范化**
   - 去掉名称首尾多余的 `|`。
   - 去掉名称末尾多余的 `:端口号`。
   - 名称为空时自动补成 `优选节点 | IP`。
   - 名称里不含 IP 时自动追加 ` | IP`。
   - 用 `\bus\s+US\b/gi` 这类正则，把出现在名称中间的小写 `us US` 替换成 emoji `🇺🇸 US`，且不受大小写和空格数量影响。

6. **按名称排序**
   用 `localeCompare` 配合 `"zh-Hans-CN"` 和 `numeric: true`，按 `#` 后面的名称排序，中文按拼音，数字按数值大小。

## 实现的功能

- **多源合并**：一次请求多个 TXT 链接，合并成一个输出。
- **规则化替换**：通过映射表把指定字符替换成另一个字符，或替换为空值。
- **时间戳清理**：自动删除形如 `09-16 09:30` 的时间片段。
- **IP 去重**：按行首 IP 去重，保留首次出现的记录。
- **名称规范化**：自动补全名称、补 IP、去掉多余分隔符和末尾端口号。
- **地区标签统一**：把中文地区名或混杂写法统一成 emoji + 地区代码格式。
- **自动排序**：按节点名称排序，中文按拼音，数字按数值。
- **单一路径输出**：所有清洗结果通过一个固定路径（如 `/bestip.txt`）输出，方便 edgetunnel 直接读取。

## 使用方式

1. 在 Cloudflare Workers 中创建 Worker，粘贴 `worker.js` 代码。
2. 按需修改 `SOURCES`（源列表）、`REPLACE_RULES`（替换规则）、`OUTPUT_PATH`（输出路径）。
3. 部署后，把 edgetunnel 的外部优选 API 地址指向 `https://你的worker地址/bestip.txt`。

## 配置说明

| 配置项 | 作用 |
|---|---|
| `SOURCES` | 要抓取的 TXT 源地址列表 |
| `REPLACE_RULES` | 字符替换规则表，键为被替换内容，值为替换后内容 |
| `OUTPUT_PATH` | 对外输出的访问路径 |

## 说明

- 替换规则按对象插入顺序依次执行，建议把更具体、更长的匹配项放在前面，避免短字符串误伤长字符串的替换结果。
- 如果某条规则的输出恰好包含另一条规则的输入，可能形成连锁替换甚至死循环。需要精确匹配的场景，建议放到名称整理阶段用 `^...$` 或 `\b...\b` 处理，而不是放进全局规则表。
- 本项目只做列表清洗，不涉及节点连接、测速或协议转换。
